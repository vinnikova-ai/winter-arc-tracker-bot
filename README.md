# Winter Arc Telegram Tracker Bot ❄️

Асинхронный Telegram-бот для отслеживания ежедневных привычек, дисциплины и прогресса в рамках марафона Winter Arc 2026.

## 🛠️ Стек технологий
* **Язык:** Python 3.14+
* **Библиотека фреймворка:** Aiogram 3.x (Асинхронное программирование)
* **База данных:** SQLite (Реляционная БД, три таблицы, кастомные SQL-запросы)
* **Планировщик задач:** APScheduler (Автоматические вечерние напоминания по расписанию)

## 🚀 Основной функционал
* **Интерактивный дашборд:** Динамический расчет текущего дня марафона (с 5 октября по 31 декабря 2026 года), пройденных и оставшихся дней.
* **Управление привычками:** Добавление целей и их полное удаление из базы данных с использованием Машины состояний (FSM) и Inline-клавиатур.
* **Глубокая аналитика:** Автоматический расчет личной эффективности и прогресса выполнения каждой привычки в процентах относительно прошедших дней.
* **Автоматические уведомления:** Фоновая регулярная рассылка напоминаний в 21:00 по московскому времени.
